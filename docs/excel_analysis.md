## 3. 明細書（中核ロジック）

### 構造
- 上部（行2〜3）: 工事名 `C3`、材料合計 `M3`、人工数 `O3`、**一律人工設定 `P3`**（=26,000。空なら品目ごとの人工単価）、手間合計 `Q3`、**一律掛率 `X3`**（=0.8）。
- 15 ブロック（ページ P1〜P15）、1 ブロック = 31 行（開始行: 5, 36, 67, 98, … 439）。
  - ブロック先頭行: `B` 工事項目No、`C` 工事項目名（例【共通仮設工事】【直接仮設工事】【屋根工事】【雨樋工事】）、`H` **ロス率**（0.07）
  - 明細 27 行、最後に 小計行（M/O/Q 列 SUM）。
- 列 A〜Q: 原価（実行予算）側。列 R〜Y: 見積単価算出。列 Z〜AP: 見積書（印刷用）へ渡す整形済み行。AR 列: データシートへのリンク用カテゴリ一覧。

### 原価計算（1行）
```
コード B         : 入力（データ!A を参照）
項目/材質/長/巾/厚/単位/使用単位/材料単価/歩掛/人工単価 : VLOOKUP(B, データ, n)
実数 H           : 入力
材料数 J = ROUNDUP(H × (1 + ロス率) / (長 × 巾), 0)
材料代 M = J × 材料単価
人工数 O = H × 歩掛
人工単価 P = 一律人工設定 があればそれ、なければマスタ値
手間代 Q = ROUNDUP(O × P, 0)
```

### 見積単価計算（行の合算・掛率）
```
R 見積行選択 : 「１行目」「２行目」… を選ぶと見積書に出す行になる
T 合算行     : 別の見積行に原価を合算する（R が空の行のみ有効。例: 棟包み+ビス を1行に）
S = R if R else T
U 原単価     = (M + Q) / H
V 合算原単価 = SUMIF(S列, S, U列)           ← 同じ見積行を選んだ行の原単価合計
W 掛率       = X(行別掛率) があればそれ、なければ X3(一律掛率)
Y 見積単価   = ROUNDUP(V / W, -2)            ← 100円単位切上げ
```

### 見積書用整形（Z〜AP）
- `AM` 見積行キー（１行目〜２７行目）、`AA` 名称（`AB` 名称編集で上書き可）、`AC` 材質（`AD` 左枠編集で上書き可）、`AH` 単位、`AI` 数量（= 実数H）、`AJ` 単価（= Y）、`AK` 金額 = AI × AJ、`AL` 備考。
- 小計行 `AK26` 等 = ブロック金額合計 → 見積書表紙とサマリーへ。
- `AN/AO`: 「使用済」判定でプルダウンから使った行を除外。`AP`: チェック用。

## 4. 営業実行予算（サマリー）

- 左側: 原価内訳 = 材料代(明細書 M3)、手間代(明細書 O3 人工 × Q3)、その他工事1〜3 小計、材工費（処分費/手数料 = 契約金額×%）、予備費 1.5%、設計監理費 5%、事業所経費 10% → **直接工事費 E17**
- ネット率別提示額: `ROUNDUP(E17 / 0.8|0.85|0.9|0.95, -4)`、想定見積金額 `E17/0.55`
- 契約予定金額 `B24`（入力）→ MQ率 / 受注MQ額
- 右側: 工事項目ごとの小計（明細書 AK 小計 ×15）→ 小計 H17、**一般管理費 8%** `G18`、**現場管理費 10%** `G19`、見積合計 H20
- 銀行別手数料率テーブル（足利/常陽/栃木/東邦/大田原信金、屋根・太陽光別）、支払条件文言 `G22`

## 5. 見積書（印刷用）

- 1ページ目（表紙）: 工事項目 No/名称/単位「式」/数量 1/金額（明細書小計）、一般管理費・現場管理費、支払条件、合計。
- 2〜16ページ: 各工事項目の明細（No/名称/材質/長/巾/厚/単位/数量/単価/金額/備考）→ 明細書の Z〜AL をそのまま参照。
- `N` 列: 次ページ番号のナビ用。28行ごとに改ページ、横向き。

## 6. 経理実行予算（案件ヘッダー・原価予算）

- 件名（=明細書 C3）、予算組日、契約日、担当者、工事場所（〒/住所/TEL/FAX）、設計事務所、ゼネコン、発注業者、契約工期、着工予定日
- 支払条件（締/払/現金%/手形%/サイト）、屋根仕様（仕様/素材/板厚/製品/色/㎡）、工事種別、情報源（新規/リピート）、備考（領収書/請求先/計上/入金予定日）
- 見積金額・契約金額・追加工事1,2・消費税10%・税込合計
- 材料費（RS材料、外注資材 屋根材/下葺材/ボード/ビス…、太陽光）、外注費（仮設、足場、解体、産廃、板金、塗装、鉄骨…）、経費（揚重機、運搬費、宿舎費、現場経費、保険料…）

  - 労災保険料 0.5%、工事監理費 5%、事業所経費 10%、直接工事費、営業荒利益 MQ
- 行 59〜96: プルダウン用選択肢マスタ（締日、支払条件、仕様、素材、板厚、製品、情報源、工事種別、領収書、請求先、計上、保険率）

## 7. Web 化（PHP + MySQL）に向けた主要エンティティ案

- `categories`（リスト/データのカテゴリ）
- `items`（データ: code, name, material, length, width, thickness, area_unit, use_unit, material_price, labor_rate, labor_price）
- `projects`（経理実行予算ヘッダー: 件名、工事場所、工期、支払条件、屋根仕様、担当者 …）
- `project_sections`（明細書ブロック: 工事項目No/名称、ロス率、表示順）
- `project_lines`（明細書行: item_code, 実数, 見積行キー, 合算先, 行別掛率, 名称編集, 材質編集, 備考）
- `project_settings`（一律人工単価、一律掛率、一般管理費%、現場管理費%、予備費% …）
- `extra_works` / `extra_work_lines`（その他工事1〜4）
- `special_notes` / `project_special_notes`（特記事項）
- `budgets`（経理実行予算 材料費/外注費/経費 の営業・工事予算行）
- マスタ選択肢（締日、支払条件、仕様、素材、情報源 …）

計算はすべて上記の式を PHP 側で再現し、見積書 PDF（表紙 + 工事項目別ページ）を出力する構成が妥当。
